# Korta AI

**An AI operations team for small businesses that keeps shelves stocked and pays suppliers on Stellar.**

Korta AI's agents spot stock that is about to run out, buy the market and supplier data they need for a
fraction of a cent each, and pay the chosen supplier's invoice in USDC — all machine-to-machine with
**x402 on Stellar**, only within the owner's spending rules and only after the owner approves.

> The AI proposes. The owner's rules decide. Stellar settles.

⚠️ **Stellar testnet only.** All payments use test USDC with no real value.

## The agent team

| Agent | Role |
|---|---|
| Inventory Agent | Flags items that will run out before the next delivery |
| Sales Agent | Forecasts demand; buys a local demand signal via x402 |
| Finance Agent | Sets how much cash can safely go to restocking |
| Procurement Agent | Buys supplier quotes via x402, compares them, places the order |
| Business Agent | Turns it all into one recommendation for the owner |
